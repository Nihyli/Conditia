# Conditia — Project Design Context

## Design Context

### Users
Two distinct audiences sharing one system of record:
- **Fleet managers / ops** — primary dashboard users. Desktop, in an office, daytime. Scanning fleet health, drilling into a truck's damage map, exporting reports, settling liability questions. Data-dense but must stay scannable.
- **Drivers / yard staff** — mobile capture only. Phone, outdoors in a yard, often gloved, bright sun or dusk. Need a dead-simple guided walk-around. (Built separately under the mobile capture flow.)

### Brand Personality
Trustworthy, precise, instrument-like. Conditia is a *system of record* for physical asset condition — the product's authority comes from being accurate, timestamped, and legible. Three words: **precise, dependable, calm.** Not flashy. The data is the hero.

### Aesthetic Direction
Light, clean fleet-operations console in the spirit of Samsara / Motive — but with its own identity.
- **Theme:** light. White/near-white surfaces, hairline neutral borders, generous whitespace, daytime legibility.
- **Layout:** persistent grouped left sidebar (MONITOR / REPORTS / INTEGRATIONS), top bar with org switcher + notifications + avatar, KPI stat row, then a two-pane work area (list of recent inspections on the left, selected-truck damage map + findings on the right).
- **Color:** restrained. Tinted-blue neutrals + a confident blue brand accent used sparingly. Severity is the only place strong color appears: Critical = red, Medium = amber, Low = blue, Clear = green. Color carries meaning, never decoration.
- **Numbers matter:** KPIs and confidence/metrics use a monospaced figure treatment (Geist Mono) for an instrument feel and clean tabular alignment.
- **Anti-references:** no glassmorphism, no gradient text, no neon-on-dark, no colored left-border accent stripes on cards, no purple/cyan AI palette. It should read like professional fleet software, not a crypto dashboard.

### Design Principles
1. **The data is the hero.** Chrome recedes; numbers, statuses, and findings lead. Color = meaning (severity), never decoration.
2. **Scannable density.** Pack real fleet information without clutter — clear grouping, consistent rhythm, tabular numerics, restrained borders.
3. **Change over time is the differentiator.** Always surface "first detected / previously detected" on findings — that's the product's whole point.
4. **Calm authority.** Light, precise, legible in an office or a sunny yard. Trust through clarity, not flourish.
5. **Severity legibility.** Critical/Medium/Low/Clear must be instantly distinguishable by color + label + icon (never color alone, for accessibility).

### Fonts
- UI / display: **Hanken Grotesk** (humanist grotesk, professional, not in the overused-default set).
- Numerics / metrics / mono accents: **Geist Mono**.
(Loaded via Google Fonts in index.html — no package install required.)
